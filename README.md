# Simple-Linear-Regression-Model
This is a simple Linear Regression Model which works on only one Feature (Feature name is Area ) , When we give the area as a input it will predict the price of the area . This is the working of this model we have used some basic and important libraries of the python like pandas , numpy , and scikit learn libraries. With the help of the pandas library data cleaning had done , we have check the null values inside the data , with the help of the visualization graphs like the "Boxplot" we have checked the outlier in the data , although we didn't find any outliers inside the data after doing the data cleaning, we have splited the data into the Train and Test after onwards we have done the scaling inside the data which help the model to learn the pattern fast then we have done the prediction and find the accuracy inside the data and last we have used a visulazation to show the predicted and actual value inside the data ."In the regplot, the regression line represents the predicted values, while the scatter points represent the actual values. The shaded region represents the confidence interval of the regression line."
